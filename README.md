# Fellowship project: start here

We are starting the project together in week 2. No prior project work is assumed.

## Question

Does making every demonstration's correct answer `(A)` change a model's answer to a new question? Does its visible explanation acknowledge that pattern?

Everyone will work from one shared baseline. Later, each participant will own one small extension. Changed answers and absent disclosure do not by themselves establish deliberate deception.

## Your first task: 10–15 minutes

1. Download `00_setup_check.ipynb` from this repository (open the file, then use Download raw file).
2. Open https://colab.research.google.com/ while signed into Google.
3. Choose File > Upload notebook and select the downloaded file.
4. Choose File > Save a copy in Drive. Rename your copy `YOUR-NAME_setup_check`.
5. Choose Runtime > Run all. No GPU, API key, package installation, or payment is required.
6. Confirm the last output says `SETUP CHECK PASSED`.
7. In Colab's left Files panel, refresh if necessary, find `setup_result.csv`, and download it. Runtime files are temporary; the downloaded file is your saved result.
8. Tell the facilitator: worked / worked with help / blocked. If blocked, include the exact error. Stop after 15 minutes rather than troubleshooting indefinitely.

The two responses are invented practice data, not real model outputs or evidence. This checks basic execution, parsing, and saving only. It does not test model inference or the full analysis pipeline.
